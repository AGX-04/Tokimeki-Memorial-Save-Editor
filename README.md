## Tokimeki Save Editor 说明

此脚本用于《心跳回忆》存档修改，可修改角色面板9项指标的数值。
1. 游戏存档文件为 tokimeki.sav 通常位于 C:\Program Files\konami\tokimeki 路径下。
2. 开始修改前强烈建议备份原始 tokimeki.sav 文件。
3. 将修改脚本与 tokimeki.sav 放入同一路径下，执行脚本，按提示操作。
4. 修改完成的存档文件为 tokimeki_mod.sav 且位于脚本同一路径。
5. 将修改完成的存档文件更名为 tokimeki.sav 并覆盖游戏存档路径下原存档sav文件即可。
6. 以上经验仅适用于PC端《心跳回忆：Forever with You》简体中文版（大众软件引进版），华艺国际繁中版未测试。


## Tokimeki Defuse Kit 说明

此脚本用于《心跳回忆》存档修改，可修改登场女角色友好、心动、伤心三大指标。
1. 游戏存档文件为 tokimeki.sav 通常位于 C:\Program Files\konami\tokimeki 路径下。
2. 开始修改前强烈建议备份原始 tokimeki.sav 文件。
3. 将修改脚本与 tokimeki.sav 放入同一路径下，执行脚本，按提示操作。
4. “对指定女生单独拆弹” 为归零指定女角色伤心度。目前测试显示伤心度达到60就会出现流言或在早乙女好雄的评价信息中出现炸弹图标。本选项不影响友好度和心动度。
5. “对指定女生心态重置” 为重置指定女角色三大心理指标。友好度会扫描其他女角色友好值，取最低值作为重置基准。心动度重置后直接回到默认的50。伤心度则会在重置时清零。
6. “一键全体拆弹” 顾名思义。仅适用于不小心打出连环雷修罗档的朋友。
7. 修改完成的存档文件为 tokimeki_safe.sav 且位于脚本同一路径。
8. 将修改完成的存档文件更名为 tokimeki.sav 并覆盖游戏存档路径下原存档sav文件即可。
9. 以上经验仅适用于PC端《心跳回忆：Forever with You》简体中文版（大众软件引进版），华艺国际繁中版未测试。
